# Task 1: CLI Expense Tracker with Persistent Storage

### Required features
- Accepts amount, category, and date.
- Stores entries as dictionaries in a list.
- Saves entries to JSON and reloads them at startup.

### Included bonus
- Monthly summary with total spending and average spending by category.

### Run
```bash
python expense_tracker.py
```

### Menu
1. Add expense
2. List expenses
3. Monthly summary
4. Exit

Dates must use `YYYY-MM-DD`. The JSON file is created automatically.
