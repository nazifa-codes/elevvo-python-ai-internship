# Task 4: Object-Oriented Inventory Management System

### Required features
- Base `Product` class and a `PerishableProduct` subclass with expiry tracking.
- `@property` validation prevents negative stock.
- Add stock, remove stock, low-inventory alerts, and formatted report.

### Included bonus
- Clean `__str__` output and `unittest` tests.

### Run
```bash
python main.py
```

### Test
```bash
python -m unittest -v
```
