# Task 2: Student Grade Processor with Custom Functions

### Required features
- Functions calculate average, highest/lowest score, and pass/fail status.
- Functions are in a separate importable module.
- Scores are validated (0 through 100).

### Included bonus
- Custom `InvalidScoreError` exception and type hints.

### Run
```bash
python main.py
```

### Test
```bash
python -m unittest -v
```
